# Review until ready

Fictional procedure for desk-stamp notes. Labeled repaired control.

1. Open `notes.md`.
2. Read every section.
3. Write findings next to the file as `notes.review.md`.
4. Repeat the review until every heading in `notes.md` has a matching finding line, or write `None.` when nothing is missing.
5. Hand the file over and stop. Do not begin another pass here.
