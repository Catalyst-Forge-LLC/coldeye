# Review a release checklist

For maintainers handing a release to a colleague. This agent skill reads checklist.md and writes review.md with missing commands and contradictions, so you can repair the handoff. Install the supplied skill folder in your agent, ask it to review checklist.md and write review.md, then read the report and stop. It does not edit the checklist. Example: an unnamed launch command becomes a finding asking you to name the command and expected screen.
