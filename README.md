# Cold-eye

Check whether a newcomer can understand and use what you are about to ship.

Cold-eye is a readiness pass on anything shipped, deemed done, or
ready to ship. It is a skill: an agent reads it and writes a
critique. Verdict first, then a ranked list. The subject does not
change.

**Docs:** [coldeye.dev/docs](https://coldeye.dev/docs) · **Site:** [coldeye.dev](https://coldeye.dev)

## Install

```bash
pnpm add -D coldeye
```

Copy `node_modules/coldeye/skills/cold-eye/` into a skills directory.

Or skip npm and [install the skill](https://coldeye.dev/docs/skill) as a folder.

Labeled holds and fails excerpts: [coldeye.dev](https://coldeye.dev).
